# Hai Phong FDI Funnel

This folder is a separate GSD project for building a marketing and commercial funnel that connects Hai Phong factory/industrial-land supply with foreign manufacturers and investors from China, Korea, Japan, the EU, and the US.

It is intentionally isolated from the current web app. No `src/`, `public/`, or `data/` web assets are modified here.

## Contents

- `ASSESSMENT.md`: objective market assessment, critique, and success model
- `CHINA_GO_TO_MARKET.md`: practical China acquisition strategy without relying on China-native social channels first
- `IMPLEMENTATION_BACKLOG.md`: ordered task list by revenue priority
- `CASE_PATTERNS.md`: public-case patterns to borrow honestly
- `TARGET_CUSTOMERS.md`: customer tiers and ICPs
- `PRODUCT_STACK.md`: what to sell first
- `EXECUTION_ORDER.md`: whether to prioritize capability deck or storytelling
- `ACCOUNT_LIST_TEMPLATE.csv`: starter template for target-account building
- `.planning/PROJECT.md`: project context
- `.planning/REQUIREMENTS.md`: v1 requirements
- `.planning/ROADMAP.md`: phased roadmap
- `.planning/STATE.md`: current working state
- `.planning/research/HAI_PHONG_CONTEXT.md`: source-backed context notes

## Why This Exists

The current site already proves there is industrial real-estate supply and basic inbound lead capture. This project exists to answer a harder question:

How do we turn Hai Phong industrial supply into a repeatable cross-border deal flow machine for serious foreign tenants and land investors?
