# Roadmap: Hai Phong FDI Funnel

## Phase 1: Wedge And Positioning

**Goal:** Choose the first customer segment, first transaction type, and first commercial promise.

**Covers:** POS-01, POS-02, POS-03

**Outputs:**

- ideal customer profile for the first wedge
- first-offer statement
- market-priority decision with explicit reasoning
- rejection list for markets/offers not pursued first

## Phase 2: Verified Supply System

**Goal:** Build the supply-quality standard required to earn investor trust.

**Covers:** SUP-01, SUP-02, SUP-03, SUP-04

**Outputs:**

- verification checklist
- opportunity data-room template
- supply quality tiers
- exclusivity/prioritized-access policy

## Phase 3: Demand Architecture

**Goal:** Build market-specific messaging and qualification logic for foreign investor acquisition.

**Covers:** DEM-01, DEM-02, DEM-03, DEM-04

**Outputs:**

- country-market message matrix
- inbound and outbound channel map
- qualification questionnaire
- response SLA and first-contact scripts

## Phase 4: Deal Operations

**Goal:** Turn leads into a disciplined and repeatable deal workflow.

**Covers:** OPS-01, OPS-02, OPS-03, OPS-04

**Outputs:**

- CRM stage design
- deal owner model
- site-visit process
- investor memo template
- landlord comparison template

## Phase 5: Proof Of Demand

**Goal:** Define and run the smallest commercial test that can prove the model.

**Covers:** PRF-01, PRF-02, PRF-03

**Outputs:**

- first-test hypothesis
- KPI targets
- case-study capture process
- clear pass/fail criteria for moving to scale

## Notes

- This roadmap is intentionally coarse because the project is still in model-definition mode.
- The next GSD move should be planning Phase 1 in detail, not building software.
